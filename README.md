# empata-match-ci-lab

Temporary isolated CI validation package for synthetic Firebase Emulator tests.

- This repository is not an operating application.
- Tests must use Firebase Auth/Firestore Emulator and synthetic data only.
- Do not connect this repository to production Firebase, Cloudflare, DNS, or real employee data.
- GitHub Actions is manual-only and must be separately approved before execution.
- Deletion of this temporary repository requires separate approval.
